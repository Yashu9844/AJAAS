# Module 7 — Assumptions

- A7-01 A user has at most one primary active Module 1 mapping; its manager_user_id is the direct manager.
- A7-02 Managers are employees too; a manager without an employee profile cannot review (counted as without_manager).
- A7-03 Criteria are cycle-wide; every review in a cycle rates the same criteria.
- A7-04 Working statuses are active, probation, notice (same as Module 6 A6-01).
